## ContextMenu 两套 API

原本 ContextMenu 对应的 API 描述为空，因此补充规范英文 JSDoc 并重新生成 API 数据，而不是手工修改生成文件。Component 接入 11 条中文描述，Primitive 接入 9 条。共享 Menu 类型新增的描述同时补入 Menu、Menubar 的已有中文资源，避免继承 API 回退英文。属性类型、导出及运行行为未改变。

## 检查结论

- en-US 与 zh-CN 注册表各 3185 个字符串叶子，缺失键与多余键均为 0。
- 520 条非空 API 描述检查通过：英文等于规范 JSDoc，中文使用本地资源且不回退英文。
- 209 个示例的标题和描述都具有中文资源，检查关闭 fallback 后仍能解析。
- `aria-label`、`title`、`placeholder` 同时检查字面量与表达式。WebsiteControlLabels 提供库内控件的本地化标签；技术名称和 ID 保留。
- 未发现源码空目录，也未发现无人引用的 locale 导出。历史样例文案仍有部分保留在资源中，不能仅凭没有直接 `t` 调用认定废弃：动态示例翻译还会按文本匹配使用资源。
- 剩余 30 个英中相同的 locale 值已按品牌、技术标识或代码/排版 specimen 保留；没有把所有英文一律替换。
